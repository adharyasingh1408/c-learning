# C Learning

Welcome to my repository for C programming! This repository tracks my journey as I build a solid foundation in low-level programming fundamentals before transitioning into complex engineering applications.

---

## 🚀 Projects Included

- **Marks & Percentage Calculator**
  - **Description:** A terminal-based program that accepts user input for five subject scores, calculates the total sum out of 500, and computes the overall percentage.
  - **Concepts Used:** Floating-point arithmetic, user input parsing, standard I/O streams, and dynamic data calculation.
  - **File:** `acchabacha.c`

- **Voting Eligibility Checker**
  - **Description:** A terminal-based program that reads a candidate's age and determines whether they are eligible to vote.
  - **Concepts Used:** Integer data types, conditional statements, comparison operators, user input parsing, and standard I/O streams.
  - **File:** `program.c`
